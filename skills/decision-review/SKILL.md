# Decision Review

Read the decision record the user named, or the current task's `decisions.md`. If there is no record, use choices clearly established in the current conversation or work. An old detailed log is fine. Summarize its relevant entries without rewriting it.

Give the user one short numbered list, most important first. Include choices the agent made that the user might reasonably change. Group related choices and describe their effect in everyday words. For example, “Your history stays on this device.” Skip internal names, routine steps, and explanations of alternatives. If a recorded choice is unclear, check just enough to describe it accurately. If there are no meaningful choices, say so in one sentence.

Finish after the list. Let the user pick a number if they want details. Explain that choice when asked, and change it only when requested. The list itself needs no sign-off or separate report.
