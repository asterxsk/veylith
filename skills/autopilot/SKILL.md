# Autopilot

The user is already away. Continue the agreed task from where you are, using the same tools, subagents, and review steps the task calls for. Make routine choices from the brief and existing preferences. Work through verification without pausing for check-ins.

If a step genuinely needs the user's input or permission, set it aside, finish the independent work, and mention what remains when you hand back.

For choices the user might want to change, append one plain-language bullet each to `decisions.md` in the working directory. Describe what the user will notice. Skip routine implementation details. Create the file only when there is a choice worth recording.
